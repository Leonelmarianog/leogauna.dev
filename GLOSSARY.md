# leogauna.dev

The personal website of Leonel Gauna: a single page that introduces him and links to his CV and profiles, in English and Spanish.

## Language

**Locale**:
One of the languages the site is published in: English (`en`, the default) or Spanish (`es`). Each Locale has its own page.
_Avoid_: Language, lang, translation

**Locale preference**:
The Locale a visitor chose explicitly with the language toggle. The site never guesses one from the browser's language.
_Avoid_: Saved language, detected language

**Theme**:
The color scheme the site is shown in: light (yellow-orange) or dark (charcoal with yellow text).
_Avoid_: Mode, color mode, skin

**Theme preference**:
The Theme a visitor chose explicitly with the theme toggle. Without one, the Theme follows the operating system's setting.
_Avoid_: Saved theme
